## Description

The player works inside a recycling center where different types of waste move through the conveyor belts. The player must quickly and correctly sort garbage into proper bins before the facility becomes overloaded.

## Controls & Gameplay

* **Sorting Mechanic:** The waste moves along the conveyor belt. **Drag and drop** the waste into the correct bin (Biodegradable, Hazardous, Recyclable, or Non-Biodegradable).
* **Increasing Difficulty:** The speed of the conveyor belt **speeds up as the game progresses**, requiring faster reflexes to keep up with the incoming waste.
* **Eco-Coins and Shop:** Earn Eco-Coins by playing Campaign Mode, which can be used to purchase new skins for the supervisor.
* **Trivia Penalty System:** If you place waste in the incorrect bin, a trivia prompt appears. Answering the trivia incorrectly deducts points, while answering correctly prevents any point deduction.

## Winning & Losing Conditions

* **Winning Condition:** Successfully sort items to reach the target score/points before the level ends.
* **Losing Conditions:** The waste touches the supervisor. And the time runs out without reaching the required points.

## How to Run / Play

1. Clone or download the whole project folder from this GitHub repository.
2. Open **Unity Hub** and click **Add project from disk** (or **Add**), then select the downloaded project folder.
3. Ensure you open the project using **Unity version 6 (6000.3.0f1)**.
4. Once the project loads in the Unity Editor, open the main scene and press the **Play** button at the top to test and play the game.

## Save Data Info

This game uses local save data (`PlayerPrefs`) to track your scores, high scores, and progression on your individual machine.
